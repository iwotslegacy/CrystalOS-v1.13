CrystalOS

Open index.html in a modern browser.

Highlights:
- Windows-style virtual filesystem with Desktop, Documents, Downloads, Pictures, Music, Videos and AppData
- App Store packages are placed in Downloads and can be removed from the Store
- Crystal Code supports index.html, style.css, script.js, server.js and package.json
- Crystal Chat supports live text/image sync between CrystalOS tabs/windows using BroadcastChannel
- Browser includes an Open in browser button
- Pointer/touch window dragging and long-press file menus for iPad/touch devices

Note: browser iframe pages can be blocked by websites that disallow embedding. The Open in browser button bypasses that by opening the current URL in a normal browser tab.

For true cross-device Crystal Chat, run a WebSocket backend; the current app provides local same-browser real-time chat without a backend.
